# Домашка из 4 уровней

В этом проекте я реализовал логику регистрации и аутентификации, написал базовый CRUD для пользователей, поработал с JWT-токенами, написал 2 миграции в базу данных

## Инструменты:

NestJS, Postgres, Docker-compose, TypeORM

## База данных

- Она поднимается в докер-контейнере. Команда для запуска: `docker compose up`

## Миграции

- Схема БД создаётся только миграциями (`synchronize: false`).
- Миграции применяются автоматически при старте приложения — `migrationsRun: true` в database.config.ts
- первая миграция `CreateUsers1791479233933` для хранения пользователей в БД
- вторая миграция `CreateRefreshTokens1791659020534` для хранения refresh-токенов, чтобы можно было управлять и отслеживать сессии пользователей

## Написаны 3 контроллера:

- первый отвечает за регистрацию/аутентификацию (`POST /auth/sign-up` — регистрация && `POST /auth/sign-in` — вход), также предусмотрен эндпоинт для выхода пользователя из аккаунта (`POST /auth/logout`) и ручка для обновления access-токена пользователя (`POST /auth/refresh`)
- второй отвечает за получение данных пользователя в конкретной сессии (`GET /profile/my`), также предусмотрен эндпоинт для редактирования профиля (`PATCH /profile/my`) и ручка для удаления профиля (`DELETE /profile/my`) удаление мягкое, логин и email остаются занятыми
- третий отвечает за пагинацию и фильтр поиска по логину (`GET /users`)

## Запуск

1. выполнить установку всех зависимостей и модулей `npm install`
2. скопировать `.env.example` в `.env` и заполнить секреты
3. поднять докер-контейнер `docker compose up`
4. запуск сервера через терминал `npm run start:dev`

## Тесты

Unit-тесты сервисов на Vitest: `npm run test`

## Документация API

После запуска Swagger доступен на `http://localhost:3000/api`
